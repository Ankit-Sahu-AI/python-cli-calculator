# Interactive CLI Python Calculator

A lightweight command-line calculator built in Python that evaluates mathematical expressions on the fly.

## Features
- Evaluates standard arithmetic expressions dynamically
- Graceful handling of division by zero and invalid inputs
- Interactive loop with a simple exit command

## How to Run
1. Ensure you have Python installed.
2. Run the script using your terminal:
   ```bash
   python cli_calculator.py
   ```
3. Type your mathematical expression when prompted, or type `exit` to quit.
